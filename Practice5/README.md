## Topics demonstrated

- Regular expression syntax and metacharacters
- Character classes and sets
- Special sequences: `\d`, `\w`, `\s`, `\D`, `\W`, `\S`, `\A`, `\Z`
- Quantifiers
- `re.search()`
- `re.findall()`
- `re.split()`
- `re.sub()`
- `re.match()`
- Regular expression flags
- Receipt parsing

## How to run

From the `Practice5` directory:

```bash
python receipt_parser.py
```

For the examples:

```bash
python RegEx/task1.py
python RegEx/task2.py
```

and so on.
